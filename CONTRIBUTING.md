# Contributing to CoolStuff

Thank you for your interest in contributing to CoolStuff!

## How to Contribute

1. Fork the repository
2. Create a new branch for your feature or bug fix
3. Make your changes
4. Test your changes thoroughly
5. Submit a pull request

## AI-Assisted Contributions

If you're using AI tools (like Claude, GPT, or other coding assistants) to vibecode a PR, please include the vibecode prompt(s) you used in the PR description. This helps maintain transparency and allows reviewers to better understand the contribution context.

## Code Style

- Follow the existing code style in the project
- Ensure your code is properly formatted
- Write clear, descriptive commit messages

## Questions?

Feel free to open an issue if you have any questions about contributing.
